Política de privacidad

Gameplays con J · Última actualización: 25 de noviembre de 2026

Esta política explica cómo Gameplays con J trata la información cuando conectas una cuenta de TikTok u otra plataforma a sus herramientas de creación y publicación de videos.

1. Información que podemos tratar

  • Datos de autorización: tokens de acceso y renovación, identificadores técnicos y permisos concedidos por la plataforma, necesarios para mantener o revocar la conexión.
  • Datos básicos de cuenta: identificador, nombre visible, avatar u otros datos de perfil que la API autorizada proporcione y que sean necesarios para identificar la cuenta o consultar sus capacidades de publicación.
  • Contenido: videos, textos, descripciones, miniaturas y ajustes que el titular proporcione o que el Servicio genere para preparar una publicación.
  • Datos técnicos: registros de ejecución y errores generados por GitHub Actions u otros componentes utilizados para operar el Servicio.

No solicitamos contraseñas de TikTok. La autenticación se realiza mediante los mecanismos oficiales de autorización de la plataforma.

2. Finalidades

Tratamos la información únicamente para conectar la cuenta autorizada, comprobar las capacidades de publicación disponibles, preparar o enviar videos cuando el titular lo solicite, mantener la seguridad y diagnosticar fallos.

3. Almacenamiento y proveedores

El proyecto puede utilizar GitHub y GitHub Actions para alojar código y ejecutar procesos. Los secretos de autorización deben guardarse en GitHub Secrets y no en archivos públicos del repositorio. GitHub puede procesar datos técnicos y registros conforme a sus propias políticas. TikTok procesa la información que recibe cuando utilizas sus servicios, conforme a su política de privacidad.

No publiques tokens, claves privadas ni credenciales en issues, código, registros o mensajes. El acceso al repositorio y a sus secretos debe limitarse a personas autorizadas.

4. Compartición

No vendemos datos personales. La información solo se transmite a la plataforma elegida cuando es necesario para la función que autorizaste, y a proveedores de infraestructura utilizados para operar el Servicio. No utilizamos los datos de TikTok para publicidad propia ni para crear perfiles comerciales.

5. Conservación y eliminación

La información se conserva solo durante el tiempo necesario para operar la conexión y las funciones solicitadas. Puedes revocar el acceso de Gameplays con J desde los ajustes de seguridad o aplicaciones conectadas de TikTok. Para solicitar la eliminación de datos asociados a la integración, escribe a ese.josue213@hotmail.com. La eliminación de secretos, archivos o registros alojados por GitHub puede requerir acciones en esa plataforma y estará sujeta a sus políticas de retención y copias de seguridad.

6. Seguridad

Aplicamos medidas razonables para proteger la información, como el uso previsto de almacenamiento de secretos y acceso restringido. Ningún sistema puede garantizar seguridad absoluta. Si sospechas que una credencial fue expuesta, revoca el acceso desde TikTok y genera credenciales nuevas.

7. Menores y cambios

El Servicio no está dirigido a menores de la edad mínima exigida por las plataformas aplicables. Podemos actualizar esta política publicando una nueva versión en esta página.

8. Contacto

Para consultas sobre privacidad o solicitudes relacionadas con tus datos, contacta a ese.josue213@hotmail.com.
